# Parrlo Chat — иконка приложения (3 варианта на выбор)

Попугай — знак Parrlo из макетов (`redesign-ios/tools/build.js`, сетка 1024). Палитра брендбука v2: #00875C, #2BC48A, #12161C, белый.
Файлы 1024×1024, без прозрачности и скруглений (маску накладывает iOS). Для каждого варианта: светлая, тёмная, tinted (iOS 18+).

| Вариант | Идея | Файлы | Лист |
|---|---|---|---|
| A | попугай с облачком «…» | `png/A-{light,dark,tinted}.png` | `png/_sheet-A.png` |
| B | облачко чата на тёмном фоне мессенджера #12161C, в нём попугай | `png/B-*.png` | `png/_sheet-B.png` |
| C | два облачка: белое и силуэт попугая (его хвост — хвост облачка) | `png/C-*.png` | `png/_sheet-C.png` |

На листах — домашний экран (60 pt, светлый и тёмный), tinted, папка (значок и открытая), 29 pt (Настройки).
`png/ref-parrlo.png` — **условный** образец иконки Parrlo для сравнения: оригинала в репозитории нет, нужен файл из брендбука.
Пересборка: `node app-icon/tools/build.js`.
