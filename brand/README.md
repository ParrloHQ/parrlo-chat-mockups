# Знаки сторонних сервисов

Только официальные файлы. Перерисовывать, перекрашивать и менять пропорции нельзя.

| Файл | Источник | Где используется |
|---|---|---|
| `apple-logo-black.svg` | Apple Design Resources → Sign in with Apple → «Logo - SIWA - Logo-only - Black» (developer.apple.com/design/resources). Оставлен только контур знака, белая подложка файла убрана | кнопка «Продолжить с Apple» (стиль «белый» на тёмном фоне) |
| `apple-logo-white.svg` | тот же контур, белый — как «Logo-only - White» | строка «Вход через Apple» в настройках аккаунта |
| `google-g.png` | Google Sign-In branding kit (`signin-assets.zip`, iOS / Dark / Pill / без текста). Знак G снят с официального SVG без фона пилюли, 160×160 | кнопка «Продолжить с Google» |

## Правила кнопок (кадры `ob-signin*`)
- **Apple** (HIG «Sign in with Apple»):
  - стиль «белый» на тёмном фоне: фон #FFFFFF, знак и текст #000000;
  - заголовок 43 % высоты кнопки (высота = 233 % кегля): 56 → 24, 44 → 19;
  - знак той же высоты;
  - форма — капсула;
  - заголовок только из утверждённых Apple: «Продолжить с Apple» / «Continuar con Apple» / «Continue with Apple», в том числе во время ожидания;
  - кнопка Apple не меньше других кнопок входа и стоит первой.
- **Google** (Google Sign-In branding):
  - тёмная тема: фон #131314, обводка 1 px #8E918F, текст #E3E3E3;
  - знак G 45 % высоты;
  - текст «Продолжить с Google» / «Continuar con Google» / «Continue with Google».
- **Общее:**
  - размер обеих кнопок не следует за размером текста системы (как у системных кнопок);
  - ожидание показывается строкой статуса и `aria-busy`, а не заменой знака или заголовка.
