# Веб-чат · вход: проверка Cloudflare Turnstile

Кадры `ob-signin-turnstile` (ожидание) и `ob-signin-turnstile-error` (ошибка), HTML без PNG; ширины 360 / 390 (`w360-n`, `w390-n`) и десктоп (`d13`, `d14`). Тема только тёмная (решение 13.11). Кнопки входа неактивны, пока проверка не пройдена.

| Ключ | ru | es | en |
|---|---|---|---|
| `check` | Проверяем, что входишь ты, а не программа. Обычно это пара секунд. | Estamos comprobando que eres tú y no un programa. Suele tardar un par de segundos. | We’re checking that it’s you signing in, not a program. It usually takes a couple of seconds. |
| `cap` | Это быстрая проверка Cloudflare: она защищает Parrlo Chat от ботов. Обычно ничего нажимать не нужно. | Es una comprobación rápida de Cloudflare que protege Parrlo Chat de los bots. Normalmente no tienes que pulsar nada. | This is a quick Cloudflare check that protects Parrlo Chat from bots. Usually you don’t need to tap anything. |
| `ph` | Место под виджет Cloudflare Turnstile · 300×65 | Espacio para el widget Cloudflare Turnstile · 300×65 | Cloudflare Turnstile widget area · 300×65 |
| `checking` | Проверка… | Comprobando… | Checking… |
| `errT` | Не удалось проверить вход | No se ha podido verificar el acceso | Couldn’t verify the sign-in |
| `errB` | Проверь соединение и попробуй ещё раз. | Comprueba la conexión y vuelve a intentarlo. | Check your connection and try again. |
| `failed` | Проверка не прошла | La comprobación no se ha completado | The check didn’t go through |
| `retry` | Повторить | Reintentar | Try again |
