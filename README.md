# parrlo-chat-mockups

Интерфейсные макеты Parrlo Chat — **не продукт**. Экраны мессенджера на трёх языках (RU / ES / EN) для разных устройств; публикуется на GitHub Pages для просмотра и обсуждения.

**Статус:** публичный репозиторий в организации [ParrloHQ](https://github.com/ParrloHQ); макеты черновые, тексты «не утверждено» не финальные.

**Просмотр:** https://parrlohq.github.io/parrlo-chat-mockups/

## Структура

| Путь | Назначение |
|---|---|
| `index.html` | Просмотрщик (язык, экран, устройство, размер текста) |
| `frames/` | HTML-кадры экранов |
| `png/` | Готовые изображения экранов |
| `persona/` | Варианты персонажа |
| `alive-parrlo/`, `alive-parrlo-front/`, `alive-parrlo-proto/` | Прототипы «живого» маскота (отдельные превью — см. README в папках) |
| `SPEC.md`, `COMPONENTS.md` | Описание экранов и компонентов |
| `mvp.json` | Разметка экранов: MVP / MVP веб (2-я очередь) / после MVP; фильтр «Выпуск» в просмотрщике |
| `docs/` | Вспомогательные заметки по адаптиву и компонентам |

## Локальный просмотр

Клонируйте репозиторий и откройте `index.html` в браузере или поднимите любой статический HTTP-сервер из корня (например, `python3 -m http.server`).

## Важно: генератор кадров

`SPEC.md` ссылается на генератор `src/gen.py` (и `src/genC.py`, `src/i18nC.py`), но в этом репозитории его нет. Экраны, добавленные 13.11 (`err-reject-*`, `home-requests`, «без звука» и «Запросы» в `home-chats-mvp`, `account-banned`, `account-suspended`, `msg-unsupported`, `group-syslines`, `ob-name`, `settings-name`, `web-provider-not-allowed`, `home-chats-mvp`), строка «Имя в профиле» и блок «Новый телефон» в `settings-account*` собраны из существующих кадров-шаблонов и правлены прямо в `frames/` и `png/`. **Если генератор перезапустят, эти изменения пропадут** — их нужно сначала внести в генератор. Разметка выпуска — `mvp.json`.
