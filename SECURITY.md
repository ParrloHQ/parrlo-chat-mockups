# Security

This repository contains static UI mockups and documentation only. It does not
ship application code or handle user data.

If you discover a security issue (for example, accidental exposure of secrets in
the repository), please report it privately:

- Open a [GitHub Security Advisory](https://github.com/ParrloHQ/parrlo-chat-mockups/security/advisories/new) for this repository, or
- Contact the repository owner via GitHub (`@MuratPod`).

Please do not open public issues for sensitive reports.
