# Редизайн iOS · листы, диалоги, контекстные меню и ошибки

Продолжение утверждённого редизайна (`../README.md`, Мурат, 22.11.2026). Стиль, токены, навбар, облачка, композер, таб-бар — из `../rd.css`; здесь только добавки (`sheets.css`). Тёмная тема, фон чата A (ровный).

- Страницы: `<экран>.html?d=se|max&t=n|ax5&l=ru|es|en`.
- Пересборка: `node redesign-ios/sheets/tools/build.js && node redesign-ios/sheets/tools/render.js` (можно передать имена экранов).
- PNG (×2): `png/<экран>__<se|max>-<n|ax5>-<ru|es|en>.png`, 23 экрана × 12 = 276 кадров. Обзор: `index.html` → `png/_overview-ru.png`.
- Проверка рендера, по каждому кадру: текст не шире своего блока, ни одно слово не разорвано между строками (Range.getClientRects), текст кнопок не выше кнопки. **Итог: нарушений нет ни на одном из 276 кадров.**
- Неразрывные пробелы: пакет использует `tools/nbsp.js` (склейка при сборке, иноязычные оригиналы помечены `lang`) + `tools/unglue.js` (порядок: раскладка → unglue → WordFit только для одиночных слов); `checks/redesign.js` по всем 23 страницам × se/max × n/ax5 × ru/es/en — **0 находок**. Ради этого изменена раскладка: на AX5 галочка в ячейках жалобы стоит над текстом; неподдерживаемое сообщение — каждое предложение с новой строки, облачко на AX5 во всю ширину.
- На AX5 работает «wordfit»: если слово не помещается, шрифт этого блока уменьшается шагами ×0,92, но не ниже 28 pt (AX1). До этого сначала меняется раскладка (плитки — столбиком, баннер — иконка над текстом, кнопки черновика — столбиком, меню — на всю ширину).

## Решения и адаптации
- **Фон.** Все оверлеи лежат на чате в стиле S2-A (ровный фон, облачка, навбар-материал, композер). Содержимое фона взято из старого кадра этого экрана (чат с Marco или группа «Квартира»), а не из S2 с Lucía: у S2 нет es/en-текстов, а у экранов ошибок фон и есть сам экран. Подпись перевода в облачке («Переведено с испанского · Показать оригинал») сохранена из старых кадров.
- **Системные алерты с текстом заменены нашим диалогом** (утверждено): радиус 28, рамка 1 px, кнопки во всю ширину. На AX5 кнопки закреплены внизу, прокручивается только текст; появляются разделитель над кнопками и индикатор прокрутки (видно на `*__se-ax5-*` диалогов).
- **Листы**: iOS 26, грабер 36×5, радиус 34 у верхних углов, плоские, фон `--surface`, ячейки `--raised` с радиусом 16. Заголовок шапки листа — 17/600, не растёт (как заголовок навбара). Текст ячеек: 17 → 34 на AX5 (тот же потолок, что у меню в утверждённом README), подписи 15 → 30.
- **Контекстные меню** — только iOS: размытие 22 + затемнение, превью, строки 44, деструктивное красным `--err`. Старые ctx-* были только десктопными (d13/d14) — нарисованы как долгое нажатие на iPhone.
- **Parrlo — отдельная вкладка**: черновики показаны на вкладке Parrlo с таб-баром; блок «Parrlo» в шапке старого списка чатов убран, вместо него бейдж «3» на круге Parrlo в таб-баре. Плюс «Новый чат» в старой шапке = кнопка «новый чат» справа (стиль S1). Кнопка «Нажми и говори» старого композера Parrlo = микрофон композера.
- Подписи нижней панели просмотра фото не растут с Dynamic Type (как таб-бар, 11 pt).
- **Текст без рода**: в ru «пока ты **сам** их не разрешишь» → «пока ты их не разрешишь»; в фоне «Чатов» ru-строка «Мама — Позвони, когда будешь свободен» заменена утверждённой в S1 «Позвони, как сможешь. Ничего срочного 🙂». Пример в жалобе «Не отвечай ему.» / «Don’t answer him.» — цитата третьего лица, оставлена дословно.
- **Поле ввода без иконок** (решение после PR 71): скрепка ○ · поле · микрофон ○, смайлика в поле нет ни на одном экране.
- **Прошедшее время с родом (ru) переписано нейтрально, помечено «не утверждено»**: «Анна присоединилась к группе» → «Анна теперь в группе»; «Оплатила свет, чек выше» (Лена) → «Свет оплачен, чек выше»; в списке «Лена: оплатила свет…» → «Лена: свет оплачен, чек выше»; «Спасибо, всё получила» (Анна Л.) → «Спасибо, всё пришло». es/en уже нейтральны.
- Плашки «не утверждено» — жёлтые пунктирные капсулы (`.tbd`), тексты дословно.

## Пропущено
- `draft-edit` без открытой клавиатуры (в старом кадре её тоже нет).
- В фоне группы не показана кнопка звонка в навбаре (навбар как в S2: назад · имя · аватар); идущий звонок — полоской под навбаром.
- web-экранов в пакете нет.
