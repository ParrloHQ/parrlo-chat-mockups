# Parrlo Chat — редизайн «как iOS, спокойно»

Статичные макеты (HTML/CSS) + PNG. Тёмная тема (плюс светлая для таб-бара — см. ниже), русский. Обзор всех PNG — `index.html` / `png/_overview.png`.

## Экраны

| Файл | Что показывает |
|---|---|
| `s1-chats.html` | «Чаты»: большой заголовок, поиск, 9 строк (Lucía, группа «Квартира» · 12 участников, Мама — закреплено, Marco, Пётр, Ирина, «Бег по субботам», Ник, Олег). Счётчик: зелёный — обычный чат, серый — чат без звука. Parrlo в списке нет. Таб-бар, активны «Чаты». |
| `s2-chat-A.html` | Чат с Lucía, фон A (ровный #12161C): перевод с испанским оригиналом, свои сообщения группой, «изменено 09:52», реакция 👍, голосовое, композер. |
| `s3-parrlo.html` | Вкладка Parrlo — чат с помощником (его облачка нейтральные, твои — зелёные), карточка напоминания, композер над таб-баром. |
| `s4-kbd.html` | Чат Parrlo с открытой клавиатурой (ЙЦУКЕН): композер над клавиатурой, таб-бара и кнопки Parrlo нет. |
| `tabbar-spec.html` | Лист спеки кнопки Parrlo в таб-баре (×3, состояния, обе темы). |
| `s3-menu.html` | То же, меню «…» открыто: Память, Голос, Язык, Тон общения, Напоминания, Что умеет Parrlo, Очистить переписку (красным). Фон под меню затемнён на 30%. |

Устройство, размер текста, тема и язык подписей таб-бара задаются в адресе страницы: `?d=se|max&t=n|ax5&th=dark|light&l=ru|es|en`.
Пересборка: `node redesign-ios/tools/build.js && node redesign-ios/tools/render.js`. Рендер заодно проверяет, не вылезает ли слово за свой контейнер.

PNG (`png/`, ×2): `{экран}__{se|max}-{n|ax5}.png` — 4 экрана × 2 устройства × 2 размера = 16 файлов (тёмная тема). Кадры для таб-бара — `png/tabbar/`, см. раздел «Кнопка Parrlo в таб-баре».
iPhone SE 375×667, safe-top 20, без индикатора «домой». Pro Max 440×956, safe-top 62, индикатор 34.

## Шрифт
Системный iOS: `-apple-system, "SF Pro Text", "SF Pro Display", Inter, system-ui`. В контейнере рендера SF Pro нет, поэтому PNG сделаны на Inter (`../fonts/Inter-Variable.woff2`). На iPhone будет SF Pro, метрики близкие.

Иерархия строится на весе и цвете, размеры почти не прыгают.

| Кнопки навбара | 17 | не растут |

Перенос по слогам выключен везде (`hyphens:none; overflow-wrap:normal`). На AX5: облачко до 90% ширины; время уходит отдельной строкой справа; строка списка складывается (аватар + имя → превью на всю ширину, до 4 строк (обычно 2) → время и счётчик); карточка в ответе Parrlo — столбиком. Проверка рендера: ни одно слово не вылезает за контейнер ни на одном PNG.

## Размеры и отступы
- Облачко: отступы 9/12 (сверху / по бокам), радиус 18, ширина по содержимому, максимум 78% колонки. Хвостик только у последнего облачка группы (угол у хвоста — 6). Внутри группы зазор 3, между группами 10.
- Время в облачке — справа внизу, на одной строке с последней строкой текста, если влезает (иначе строкой ниже). Галочки рядом со временем, только у своих.
- Перевод: разделитель 1px на всю ширину облачка, подпись «Оригинал» 12/600, оригинал 15 приглушённым.
- Голосовое: белая кнопка ▶ 44 (AX5 — 72), волна из столбиков 3px, длительность под волной.
- Реакция: капсула 26 — эмодзи + аватар 20.
- Навбар: 52 + safe-top, кнопка «‹» и аватар — круги 36, заголовок по центру.
- Композер: скрепка ○36 · поле-капсула 36 «Сообщение» без значков (смайлик — на системной клавиатуре) · микрофон ○36. Всё нейтральное.
- Список: аватар 52, поля 16, строка от 76, разделитель 0,5 от начала текста. Счётчик 20.
- Таб-бар: системный, во всю ширину, 49 + индикатор «домой». Контакты · Звонки · [Parrlo] · Чаты · Настройки, активный — #2BC48A (в светлой теме #00875C).
- Меню: радиус 14, строки 44, разделители 0,5, иконка справа, перед «Очистить переписку» — отбивка 8.
- Отступ от краёв экрана 16 (облачка — 8 + хвостик 6).

## Что изменилось по сравнению со старым стилем
- Без градиентов, стекла, бликов, теней и свечения. Все кнопки плоские: заливка токеном (#242B34) и, где нужно, рамка 1px.
- Зелёный только на своих облачках (плюс активная вкладка и счётчики). Голубого нет, кнопка микрофона нейтральная.
- Текст облачков — обычный 17, не жирный. Заголовки — полужирные, без скачков размера.
- Навбар тонкий, как в iOS: «‹» в круге, имя и статус по центру, аватар справа. Контент под ним только размыт.
- Таб-бар — системный, во всю ширину, вместо плавающей «пилюли». Parrlo — отдельная вкладка, а не строка в списке чатов. Настройки помощника — в меню «…».
- Облачка по ширине текста, сгруппированы, хвостик только у последнего, время внутри облачка.
- Фон чата — ровный (A).
- Статусы без рода: «в сети», «недавно в сети».

## Кнопка Parrlo в таб-баре — спека для кода
Лист спеки: `tabbar-spec.html` → `png/tabbar/_spec.png` (×3, размеры на рисунке анатомии измерены по самому макету).

**Таб-бар — системный iOS 26**, 5 вкладок: Контакты · Звонки · Parrlo · Чаты · Настройки. У системной вкладки №3 подписи нет — поверх неё лежит наша кнопка.
- Высота 49 + индикатор «домой» (34 на Pro Max, 0 на SE). Материал с размытием, волосяная линия 0,5 сверху (внутри 49).
- Иконки 26, подписи 10 pt medium. Неактивная — muted, активная — акцент (#2BC48A тёмная / #00875C светлая).
- **На AX5 таб-бар не меняется**: подписи остаются 10, иконки 26 (полный текст — через Large Content Viewer). Прежнее правило «на AX5 подписи скрыты» убрано.

**Кнопка**
- Круг **60 × 60, фиксированный**: не растёт с Dynamic Type, на AX5 тот же.
- По центру 3-й вкладки по горизонтали; **выступает над верхней кромкой панели на 12** (низ круга — 48 от верха панели, на 1 выше её нижнего края 49).
- Попугай 30 × 32 по центру круга.
- Подписи нет (утверждено).
- Плоско: без тени, свечения, градиента; нажатие меняет только заливку, без масштабирования.

## Неразрывные пробелы и проверка в CI
Короткие служебные слова (предлоги, союзы, артикли — общий список `tools/short-words.json`, копия `shared/short-words.json` из parrlo-app) не остаются в конце строки: `tools/nbsp.js` при сборке ставит U+00A0 после них, перед «же / ли / бы» и перед «—». Язык — по ближайшему `lang` (испанские оригиналы помечены `lang="es"`). Если склеенная цепочка не помещается в строку (AX5), `tools/unglue.js` в странице рвёт склейку там, где цепочка перестаёт влезать: целое слово важнее склейки (порядок 22.11: раскладка → снять склейку → WordFit). Пакеты (`settings/`, `onboarding/` …) подключают те же `tools/nbsp.js` и `tools/unglue.js`.
CI (`hov`, `wbr`) запускает `checks/redesign.js` на всех страницах `redesign-ios/**` × SE/Pro Max × n/AX5 × ru/es/en: вылеты за экран, разрывы слов, висячие короткие слова (кроме случая, когда вся склеенная цепочка шире строки). Ожидается 0.
