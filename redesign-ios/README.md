# Parrlo Chat — редизайн «как iOS, спокойно»

Статичные макеты (HTML/CSS) + PNG. Тёмная тема, русский. Обзор всех PNG — `index.html` / `png/_overview.png`.

## Экраны

| Файл | Что показывает |
|---|---|
| `s1-chats.html` | «Чаты»: большой заголовок, поиск, 9 строк (Lucía, группа «Квартира» · 12 участников, Мама — закреплено, Marco, Пётр, Ирина, «Бег по субботам», Ник, Олег). Счётчик: зелёный — обычный чат, серый — чат без звука. Parrlo в списке нет. Таб-бар, активны «Чаты». |
| `s2-chat-A.html` | Чат с Lucía, фон A (ровный #12161C): перевод с испанским оригиналом, свои сообщения группой, «изменено 09:52», реакция 👍, голосовое, композер. |
| `s2-chat-B.html` | То же, фон B: силуэты попугая и точки тон-в-тон, белый 3,5%. |
| `s3-parrlo.html` | Вкладка Parrlo — чат с помощником (его облачка нейтральные, твои — зелёные), карточка напоминания, композер над таб-баром. |
| `s3-menu.html` | То же, меню «…» открыто: Память, Голос, Язык, Тон общения, Напоминания, Что умеет Parrlo, Очистить переписку (красным). Фон под меню затемнён на 30%. |

Устройство и размер текста задаются в адресе страницы: `?d=se|max&t=n|ax5`.
Пересборка: `node redesign-ios/tools/build.js && node redesign-ios/tools/render.js`. Рендер заодно проверяет, не вылезает ли слово за свой контейнер.

PNG (`png/`, ×2): `{экран}__{se|max}-{n|ax5}.png` — 5 экранов × 2 устройства × 2 размера = 20 файлов.
iPhone SE 375×667, safe-top 20, без индикатора «домой». Pro Max 440×956, safe-top 62, индикатор 34.

## Шрифт
Системный iOS: `-apple-system, "SF Pro Text", "SF Pro Display", Inter, system-ui`. В контейнере рендера SF Pro нет, поэтому PNG сделаны на Inter (`../fonts/Inter-Variable.woff2`). На iPhone будет SF Pro, метрики близкие.

## Типографика (pt = px)
Иерархия строится на весе и цвете, размеры почти не прыгают.

| Роль | Normal | AX5 |
|---|---|---|
| Большой заголовок «Чаты» | 34 / 700 | 48 (потолок ×1,4) |
| Текст в облачке (Body) | 17 / 400, межстрочный 22, никогда не жирный | 53 / 64 |
| Имя в списке | 17 / 600 | 53 |
| Превью в списке, оригинал перевода | 15 / 400 | 49 |
| Время в списке | 14 | 40 |
| Время / «изменено» в облачке, «Оригинал», длительность | 12 | 40 |
| Плашка даты | 13 / 600 | 44 |
| Заголовок навбара / статус | 17 / 600 · 12 | не растут |
| Подписи таб-бара | 10 / 500 | скрыты, как в iOS: только иконки (подпись — через Large Content Viewer) |
| Кнопки навбара («Изм.») | 17 | не растут |
| Плейсхолдер поиска и композера | 17 | 28 — наш потолок, чтобы «Сообщение» и «Поиск» не обрезались |
| Пункты меню Parrlo | 17 | 34 (×2) — наш потолок; меню на всю ширину минус 16 |

Перенос по слогам выключен везде (`hyphens:none; overflow-wrap:normal`). На AX5: облачко до 90% ширины; время уходит отдельной строкой справа; строка списка складывается (аватар + имя → превью на всю ширину → время и счётчик); карточка в ответе Parrlo — столбиком. Проверка рендера: ни одно слово не вылезает за контейнер ни на одном из 20 PNG.

## Размеры и отступы
- Облачко: отступы 9/12 (сверху / по бокам), радиус 18, ширина по содержимому, максимум 78% колонки. Хвостик только у последнего облачка группы (угол у хвоста — 6). Внутри группы зазор 3, между группами 10.
- Время в облачке — справа внизу, на одной строке с последней строкой текста, если влезает (иначе строкой ниже). Галочки рядом со временем, только у своих.
- Перевод: разделитель 1px на всю ширину облачка, подпись «Оригинал» 12/600, оригинал 15 приглушённым.
- Голосовое: белая кнопка ▶ 44 (AX5 — 72), волна из столбиков 3px, длительность под волной.
- Реакция: капсула 26 — эмодзи + аватар 20.
- Навбар: 52 + safe-top, кнопка «‹» и аватар — круги 36, заголовок по центру.
- Композер: скрепка ○36 · поле-капсула 36 «Сообщение» со смайликом справа · микрофон ○36. Всё нейтральное.
- Список: аватар 52, поля 16, строка от 76, разделитель 0,5 от начала текста. Счётчик 20.
- Таб-бар: системный, во всю ширину, 49 + индикатор «домой». Контакты · Звонки · Чаты · Parrlo · Настройки, активный — #2BC48A.
- Меню: радиус 14, строки 44, разделители 0,5, иконка справа, перед «Очистить переписку» — отбивка 8.
- Отступ от краёв экрана 16 (облачка — 8 + хвостик 6).

Своё облачко #1F6B4E — приглушённый тёмный зелёный, производный от бренда #00A86B (тот же оттенок, меньше насыщенности и светлоты). Не кислотный и не спорит с акцентом #2BC48A.
Материал панелей: #12161C 82% + blur 20 + saturate 140%. Слой размытия заходит за край панели на 48px и обрезается маской, поэтому у кромки текст тоже не читается.

## Что изменилось по сравнению со старым стилем
- Без градиентов, стекла, бликов, теней и свечения. Все кнопки плоские: заливка токеном (#242B34) и, где нужно, рамка 1px.
- Зелёный только на своих облачках (плюс активная вкладка и счётчики). Голубого нет, кнопка микрофона нейтральная.
- Текст облачков — обычный 17, не жирный. Заголовки — полужирные, без скачков размера.
- Навбар тонкий, как в iOS: «‹» в круге, имя и статус по центру, аватар справа. Контент под ним только размыт.
- Таб-бар — системный, во всю ширину, вместо плавающей «пилюли». Parrlo — отдельная вкладка, а не строка в списке чатов. Настройки помощника — в меню «…».
- Облачка по ширине текста, сгруппированы, хвостик только у последнего, время внутри облачка.
- Два фона чата: ровный (A) и едва заметный узор (B).
- Статусы без рода: «в сети», «недавно в сети».
