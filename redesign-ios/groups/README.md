# Parrlo Chat — редизайн iOS · группы

Пакет экранов групп в утверждённом стиле редизайна (`../README.md`, `../rd.css`): тёмная тема, фон чата A (ровный), плоские кнопки, навбар из материала, облачка #1F6B4E / #22272F. Тексты — дословно из старых макетов `frames/{ru,es,en}-<экран>.html` (фигура `__pro-n`), включая пометки «не утверждено» (жёлтые пунктирные пилюли `.tbd`).

Страница экрана — `<экран>.html?d=se|max&t=n|ax5&l=ru|es|en`. Обзор — `index.html` → `png/_overview-ru.png` (Pro Max, обычный текст, ru).
PNG: `png/<экран>__<se|max>-<n|ax5>-<ru|es|en>.png`, ×2 — 30 экранов × 2 × 2 × 3 = **360 файлов**.

Пересборка:
```
python3 redesign-ios/groups/tools/extract.py   # тексты из старых кадров → tools/strings.json
node redesign-ios/groups/tools/build.js        # страницы, groups.js, index.html
node redesign-ios/groups/tools/render.js       # PNG + проверка → tools/check.txt
```
`build.js` берёт каждую строку по ru-тексту из `strings.json` (ru/es/en сопоставлены по порядку текстов в старом кадре); нет строки — сборка падает, поэтому своих текстов в макетах нет.

## Решения и адаптации
- **Навбар чата группы**: «‹» · название и «12 участников» по центру · справа кнопка «Групповой звонок» и аватар группы («О группе»). Вместо «…» старого кадра — аватар, как в утверждённом чате с Lucía.
- **Строка ИИ** («Здесь может использоваться ИИ-помощник…») и **плашка идущего звонка** — часть материала навбара, закреплены под ним (как плашка звонка в Telegram iOS). На AX5 их текст растёт до потолка 24 (иначе на SE они занимают пол-экрана).
- **Имена отправителей** — над первым облачком группы, светлые тона цветов аватаров: `--nt-0…3` = #4CD6A0 / #E8AE4C / #93ACF5 / #EE93C6 (на #12161C ≥ 7:1; сами --av-* как цвет текста на тёмном фоне не проходят 4,5:1). Аватар 28 (AX5 — 44) — у последнего облачка группы. Свои облачка — без имени.
- **Системные строки** — по центру, приглушённые (#9AA4B2 на капсуле #242B34, как плашка даты, но 13/500). Строки про админа/владельца — со значком щита.
- **«Переведено с испанского · Показать оригинал»** — подвал облачка с разделителем, как блок «Оригинал» в утверждённом S2; время — в подвале.
- **О группе** (`group-members` и варианты) — в стиле iOS: большой аватар 96, название, «12 участников», три плитки действий (Групповой звонок, Ссылка-приглашение, Parrlo в группе — подписи взяты из соседних старых кадров), инсет-группы. Заголовок навбара — «Участники и права» из старого кадра. «Добавить участников» перенесена из нижней кнопки в первую строку списка участников (как «Добавить» в iOS); в `group-members-empty` она осталась кнопкой внизу. Строка «Группа «Квартира» · 12 участников» заменена шапкой (название + «12 участников»).
- **Меню участника** — шит действий iOS; подтверждения — алерты iOS: «Отмена» слева (жирная при разрушительном действии), действие справа; на AX5 алерт во всю ширину минус 16, кнопки в столбик, «Отмена» внизу.
- **Новая группа**: «Отмена» перенесена в навбар слева (модальный экран iOS). Клавиатура не показана.
- **Ссылка-приглашение**: действия — строки инсет-группы (как в Telegram iOS), «Сбросить ссылку» — отдельной группой красным.
- **Parrlo в группе**: описания выключателей — подписи под секцией (footer iOS). Выключатели плоские, без тени.
- **Выбор админа**: один выбор — галочка справа; множественный (новая группа) — круги выбора слева.
- **Звонок**: протокол (боковая панель старого кадра для широких экранов) на iPhone не показан — открывается кнопкой «Полный протокол». Красная кнопка завершения плоская.
- Таб-бара нет: все экраны пакета — вложенные (как чат S2).
- Пометки `.tbd` — фиксированные 12 pt (это пометки для команды, а не интерфейс).

## AX5 и проверка
Раскладка AX5: строка участника складывается (аватар и «…» сверху, имя и роль на всю ширину), плитки действий — строками во всю ширину со значком слева, карточка приглашения — столбиком, значения ячеек «ключ — значение» — под названием, выключатель — над подписью, у плашки звонка кнопка — под текстом. Потолки: заголовки экранов 44, большие кнопки 28, алерты 34/28, плашки под навбаром 24.
Затем WordFit (`groups.js`, как `wordfit.js`): если слово всё равно не помещается — кегль блока ×0,92 ступенями, не ниже AX1 (×0,53). Где сработал — в `tools/check.txt`.
`render.js` на каждом из 360 кадров проверяет: нет элементов с текстом, где scrollWidth > clientWidth; ни одно слово не разорвано между строками и не вылезает за свой блок. Итог — в `tools/check.txt`.
