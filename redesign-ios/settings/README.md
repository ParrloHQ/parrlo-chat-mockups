# Parrlo Chat — редизайн iOS · «Настройки»

Вкладка «Настройки» и её подэкраны в утверждённом стиле редизайна (см. `../README.md`, `../rd.css`). Тёмная тема, фон A, плоские кнопки, системный таб-бар с кругом Parrlo 60.
Обзор: `index.html` → `png/_overview-ru.png` (все экраны, Pro Max, обычный текст, ru).

Адрес страницы: `<экран>.html?d=se|max&t=n|ax5&l=ru|es|en`.
Пересборка: `node redesign-ios/settings/tools/build.js && node redesign-ios/settings/tools/render.js` (можно передать имена экранов).
PNG: `png/<экран>__<se|max>-<n|ax5>-<ru|es|en>.png` — 18 экранов × 2 устройства × 2 размера × 3 языка = **216** файлов.

## Решения и адаптации
- **Секция «Parrlo» в корне заменена одной строкой «Parrlo»** с подписью «Память, голос, тон общения и язык ответов — теперь во вкладке Parrlo.» (es/en — по смыслу так же) и шевроном (ведёт во вкладку Parrlo). Текст новый — помечен «формулировка: не утверждено». Прежние строки «Тон общения», «Язык ответов», «Память» убраны.
- В корень добавлена секция без заголовка: **«Использование» и «Тарифы»** (названия — заголовки старых экранов `usage` / `plans`), иначе на эти экраны из вкладки не попасть.
- Списки — inset-grouped iOS: заголовок секции 13 (без капса — спокойнее), ячейки #1C2026 радиус 14, строки от 44, разделитель 0,5 от начала текста, плитки иконок 29 (радиус 7) с белым глифом там, где в старых кадрах были иконки; иконки — из старых кадров. Значение справа приглушённым, шеврон.
- Переключатели плоские iOS 51×31: включён — #2BC48A, выключен — #3A424D, неактивный — 40%.
- Подэкраны — системная навигация: «‹» в круге + заголовок по центру в навбаре (материал). Где старый заголовок — фраза («Удалить аккаунт?», «Дневной лимит Parrlo исчерпан», «Лимит сброшен»), он в теле экрана (Title 1, 28/700), навбар без заголовка.
- Таб-бар — только на корне; на вложенных экранах он скрыт (как push с hidesBottomBarWhenPushed), чтобы кнопки действий были внизу.
- Кнопки действий внизу — на материале (blur), капсулы 50: основная #00875C, опасная — #3C2A2E с текстом #FF6B5E (4,81:1), «Отмена» / «Понятно» — текстом #2BC48A. Без теней и градиентов.
- «Сохранить» на экране имени перенесён в навбар справа (как в iOS); счётчик 5 / 60 — в подписи под полем.
- Подтверждения выхода и удаления (шаг 2) — алерт iOS: 270, кнопки столбиком, опасная красным, «Отмена» полужирная.
- Баннеры ошибки / блокировки / успеха — ячейка с плиткой (красная ×, серый колокольчик, зелёная галочка) вместо цветных плашек.
- Полоска лимита: дорожка #2F3640, Parrlo #2BC48A, Голос #FFC247, Звонки #6AA6F5; исчерпанная — целиком #FF6B5E (в старом — красная обводка).
- Попугай 64 над заголовком лимита — только на Pro Max в обычном размере (в старом он тоже скрыт на компактных).
- Пометки «не утверждено» / «юрист проверит» — пунктирные жёлтые пилюли `.tbd`, тексты дословно.

## Отступления от текстов старых кадров
- ru, «Напоминание про Parrlo»: «Сейчас выключено: ты выбрал «Не напоминать»» → «Сейчас выключено: выбрано «Не напоминать»» — правило «не указывать род пользователя». es/en рода не содержат — без изменений.
- Подсказка на экране языка ссылалась на «Настройки → Parrlo → Ещё». Теперь: ru «вкладка Parrlo → «…» → Язык», es «pestaña Parrlo → «…» → Idioma», en «Parrlo tab → “…” → Language» + пометка «не утверждено».
- `settings-notifications-blocked`: веб-текст («Браузер блокирует уведомления», шаги про значок у адреса сайта) заменён iOS-текстом от координатора, с пометкой «не утверждено»: ru «Уведомления выключены. Включи их: Настройки iPhone → Parrlo → Уведомления.», es «Las notificaciones están desactivadas. Actívalas en Ajustes del iPhone → Parrlo → Notificaciones.», en «Notifications are off. Turn them on in iPhone Settings → Parrlo → Notifications.» Шаги: 1. Настройки iPhone / Ajustes / Settings · 2. Parrlo · 3. Уведомления / Notificaciones / Notifications.
- `plans`, текст подписки: вместо «[с налогами/IVA — подтвердить менеджеру Store]» стоит `{price}` (ru «Цена — {price}.», es/en «Precio: {price}.» / «Price: {price}.») — локализованная строка цены из StoreKit, налог уже в ней. Плашка «не утверждено» остаётся. Остальные тексты — по вычитке Переводчика 22.11 (`docs/tbd-texts-review.md`).
- `settings-about`: «hello@parrlo.com» и «Политика конфиденциальности» в тексте оператора — ссылки зелёным.

## Dynamic Type (AX5)
Строки складываются: плитка и шеврон / переключатель — первой строкой, название на всю ширину ниже, значение — под названием. Плитка 44, переключатель 64×39. Кнопки и алерты растут до 34 (потолок как у меню Parrlo), алерт — на всю ширину минус 16. Пометки `.tbd` на AX5 — 28 (служебные).
Если слово всё равно не помещается, шрифт этого блока уменьшается шагами ×0,92, не ниже 28 (wordfit в скрипте страницы). Сработало в 45 кадрах (AX5): самые сильные — «Политика конфиденциальности» на SE (→ 30), текст оператора (→ 30), «Отключить все push-уведомления» (→ 32), «hello@parrlo.com» (→ 35).

## Проверка рендера
Пакет использует `tools/nbsp.js` (склейка коротких слов при сборке) + `tools/unglue.js` (порядок в странице: раскладка → unglue → WordFit; если WordFit уменьшил блок, склейка этого блока пересчитывается по новой ширине); `checks/redesign.js` по всем 18 страницам × se/max × n/ax5 × ru/es/en — **0 находок**.

`tools/render.js` на каждом из 216 кадров проверяет: текст не шире своего блока (scrollWidth), блок не вылезает за родителя и экран, ни одно слово не разорвано между строками (Range по каждому слову). Слова с дефисом или «/» (e-mail, push-уведомления, налогами/IVA) не переносятся. **Итог: переполнений и разрывов слов нет.** (Первый прогон нашёл переполнение строки «Обнулится в понедельник…» на SE AX5 — исправлено.)
